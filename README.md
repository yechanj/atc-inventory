# ATC 카세트 재고·보충 관리 (MVP)

병원 원내약국 ATC(자동정제분류포장기) 카세트의 **이론재고**를 추적하고, 매일 보충해야 할
카세트를 빠르게 파악하기 위한 웹앱입니다.

핵심 흐름: **PamPro 사용량 Excel 업로드 → 직전 대비 신규 사용량 자동 차감 → 오늘 보충 화면 확인 → 실제 보충량 입력**

## 기술 스택
- Next.js 14 (App Router) + TypeScript
- Prisma ORM + SQLite (`prisma/dev.db`) — 병원 PC 로컬/오프라인 실행. 추후 PostgreSQL 전환 가능.
- Tailwind CSS

## 실행 방법
```bash
npm install
npx prisma db push          # DB 스키마 생성 (최초 1회)
npm run db:seed             # sample-data의 PamPro 파일로 카세트 마스터 생성(현재고 1000)
npm run dev                 # http://localhost:3000
```

### 유용한 스크립트
- `npm run parse:check` — sample-data의 모든 파일을 파서로 검증(집계/비카세트/소수/합산 확인)
- `npm run db:seed` — 카세트 마스터 부트스트랩 (이미 있으면 건너뜀, 현재고 1000)

## 화면
| 경로 | 설명 |
|---|---|
| `/` | 대시보드 (요약) |
| `/today` | **오늘 보충** — 보충기준 이하 카세트만, 카세트번호순, 즉시 보충 |
| `/cassettes` | 전체 재고표 (검색/필터/정렬, 보충·보정·설정) |
| `/upload` | PamPro 사용량 업로드 → 미리보기 → 반영 |
| `/stocktake` | 재고조사 모드 (실제재고 일괄 보정) |
| `/history` | 재고 변동 기록 |

## PamPro 파일 형식 (실측 기준)
- 확장자는 `.xls`지만 실제로는 **CP949(EUC-KR) 탭 구분 텍스트**.
- 컬럼: `No. | 제품ID(호기) | 캐니스터번호 | 약품코드 | 약품명 | 총 사용량 | 횟수`
- 파서(`lib/pampro/parseUsageFile.ts`)가 처리하는 특성:
  - 캐니스터번호가 빈 행 = 수동조제 → 재고 추적 제외
  - 같은 (캐니스터번호+약품코드)가 여러 행 → 합산 (제조사 표기 차이)
  - **같은 캐니스터번호라도 약품코드가 다르면 별도 처리** (한 카세트가 다른 약을 조제한 날 대응)
  - 소수 사용량(예 159.5) 허용
  - 매칭 키는 **(호기 + 캐니스터번호 + 약품코드)**

## 재고 계산 모델
- **사용 발생**: 현재고 −= 신규 사용량 (`신규 = 이번 누적 − 직전 반영 누적`)
- **보충**: 현재고 += 실제 보충수량 (포장단위 또는 직접 수량)
- **실재고 보정 / 재고조사**: 현재고 = 실제 계수값

### 데이터 안전장치
- 동일 파일 **중복 반영 차단** (원본 바이트 SHA-256)
- **사용량 감소 감지**: 직전보다 누적이 작으면 조회기간 변경 의심 → 자동 반영 제외 + 경고
- **약품 매칭 실패**: 무시하지 않고 미매칭/수동조제 목록으로 표시
- 모든 재고 변경은 **트랜잭션**(전체 성공 또는 전체 롤백) + `InventoryHistory` 기록
- 이론재고 음수 시 0으로 보정 + "확인 필요" 표시

## 데이터 모델 (`prisma/schema.prisma`)
`Hospital → Machine → Cassette`, `UsageSnapshot → UsageSnapshotLine`, `InventoryHistory`.
멀티테넌시(`hospitalId`)·다호기(`machineId`)를 처음부터 반영 → SaaS 확장 대비.

## 참고 — 초기 테스트 데이터
- 실제 초기재고 미조사 상태이므로 모든 카세트 현재고를 **임시 1000정**으로 부트스트랩.
- 전수 재고조사 후 `/stocktake`에서 실제 수량을 일괄 입력하면 그 시점부터 정식 추적됩니다.
- 참고: 제공된 PamPro 파일에는 **1호기 외에 2호기**도 포함되어 있어 두 장비가 자동 생성됩니다.
